# CMA 台风报文存档

本仓库归档了中国气象局（CMA）2025-06 之后发布的台风报文。

## 数据来源

数据来自中央气象台（NMC）台风报文页面：

https://nmc.cn/publish/typhoon/message.html

## 数据格式

历史报文采用 JSON Lines（JSONL）格式存储，每行是一条独立的 JSON 记录。

```text
data/
└── archive/
    ├── 2025/
    │   ├── 2025-09.jsonl
    │   ├── 2025-10.jsonl
    │   └── ...
    └── 2026/
        ├── 2026-01.jsonl
        └── ...
```
